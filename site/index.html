02 · 她会什么

她只聊天，
也认真听。

不读写文件、不执行命令、不操作应用。需要查资料或看屏幕时，她会先问，再把真实来源留下。

01

声音同步

每个字跟随真实播放进度，静音也有同样的阅读节奏。

02

八套主题

夜墨、茶白、苔绿、雾蓝、樱夜、晴空、琥珀、竹月。

03

会记得

跨话题摘要和长期记忆，保存、观察和偷看都能单独关闭。

04

慢慢来

先文字聊天，语音包稍后下载；镜像加速、断点续传。

  1. 01

    下载安装包

    per-user 安装，不要求管理员权限。安装完成后直接启动 Ayana。

  2. 02

    填好 API Key

    打开「设置 → 模型与连接」，填写服务地址、模型名称和 API Key。密钥使用当前 Windows 用户的 DPAPI 加密，不写入设置文件。

  3. 03

    和她见面

    在开屏导览里设置称呼、主题、服装和快捷键。语音包可以稍后再下载，不会挡住文字聊天。
