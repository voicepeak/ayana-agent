07 · 常见问题

安装之前，
你可能想问。

还有问题？到 GitHub Issues 或 Discussions 留一句。

需要准备什么？

Windows 10/11 x64，以及一个 OpenAI 兼容接口的 API Key 和模型名称。推荐 DeepSeek：服务地址 https://api.deepseek.com，模型 deepseek-flash。

没有 API Key 可以先用演示模式吗？

不能。0.3.26 已移除本地演示模型，首次进入桌面前必须配置 API Key 与模型名称。

语音包有多大？必须先下载吗？

不必。没有语音包时，对话会自动按纯文字显示。CPU 语音包约 4.86 GB，CUDA 版本约 8.3–9.5 GB；应用内下载会自动选择镜像并使用多线程分段续传。

安装包和便携版有什么区别？

安装包使用 per-user NSIS，一键安装并创建快捷方式；便携版双击即可运行，不写入安装目录。两者使用同一个 %APPDATA%\Ayana 配置目录。

API Key 存在哪里？

使用当前 Windows 用户的 DPAPI 加密保存在本机，不写入 config/local.json，界面和日志不会回显密钥。也可以改用 AYANA_API_KEY 或 DEEPSEEK_API_KEY 环境变量。

这一版还有白制服彩名吗？

没有。当前发布版只提供黑制服彩名，设置和开屏都不再出现白制服切换；便签内保留黑制服、内衣与裸露三种服装状态。
