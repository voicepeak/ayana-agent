# 连续对话与对话管理

日常使用直接接着聊。呼出、换窗口和后台整理都不会自动创建另一段对话，也不用先决定这句话属于哪个话题。需要主动重新开始或继续旧对话时，直接点彩名窗口顶部的当前对话名称。

## 三种保存内容

| 内容 | 用途 | 整理后如何保留 |
| --- | --- | --- |
| 完整对话记录 | 查看原话、搜索、导出 | 保存在本机 SQLite，摘要不删除原记录 |
| 当前对话的模型上下文 | 延续最近讨论与任务 | 较早的完整轮次变成摘要，保留最近轮次 |
| 个人记忆 | 延续用户明确说过的长期事实和偏好 | 独立保存，跨对话使用，可修改或忘记 |

用户消息、模型回答、日语原文、中文字幕和播放回执仍按原来的记录路径保存。摘要与个人记忆不会代替完整的记录。

## 自动维护

联网模型完成当前回复后才排队整理，不占用桌面工具往返次数。上下文接近现有字符预算的 85% 时开始后台摘要，尽量保留最近六个完整轮次；特殊大消息仍使用原有的硬预算兜底。当前 64,000 字符请求预算和工具任务限制不在本次修改中任意上调。

后台摘要使用轮次快照。保存前会核对轮次是否仍然存在且前缀一致；切换对话时只能更新原对话，删除对话后不得写回。失败保留原上下文，原记录始终可查。

个人记忆默认开启，需要同时开启本机历史保存。积累至少四条待处理用户消息后整理一次，每批最多十二条。首次从最近十二条开始，之后按顺序消费新增消息。每批最多提取六条，最多保留四十条有效记忆；当前模型请求携带的记忆限制为 6,000 字符。这是首版有限容量的个人记忆，还没有全历史的语义检索。

整理只使用用户消息，要求提供确实出现过的原文引用。模型负责挑选长期事实和偏好；后端校验引用与来源，拒绝编造引用。问候、短期操作、问题、玩笑、屏幕内容和助手的说法不应进入个人记忆。引用校验不能替代语义准确性判断，用户可在管理页查看和修正。

修改过的记忆受保护，不被自动提取覆盖。忘记后删除该条内容和引用，并保留无正文的标记及来源 ID，防止同一条原话再次被提取。原对话记录仍可查看。关闭自动记忆后停止提取与携带，已存记忆保留。没有开启历史保存时不提取或携带个人记忆。

记忆作为当前请求末尾的临时数据发送，不复制到每轮保存的历史里。这样下一次修改或忘记可以立即影响携带内容，也保留历史请求前缀的稳定性。历史原话和助手已说过的内容仍可能出现在当前对话上下文中。

记忆整理单次超时 25 秒，失败后至少冷却五分钟；后台摘要总时限 48 秒。它们是额外的普通模型请求，少量增加模型用量。API 返回用量时，保存为 `maintenance.usage`，用 `personal_memory`、`history_summary` 区分；主任务的 `model.usage` 不被这些请求覆盖。请求详情可通过既有的受认证调试接口查看。

## 管理入口与操作

彩名窗口顶部显示当前对话名称，点击后可查看所有对话、按标题和最近消息筛选、直接切换或新建，全程留在聊天界面。选择当前对话只收起列表；切换其他对话会停止当前任务与语音。每段对话尚未发送的输入各自保留在本次运行中，已发送输入不会再次恢复。

详细整理通过「更多操作」里的「话题与记录」，或管理窗口侧栏的「对话与记忆」进入。记录页支持跨对话全文搜索、日期范围、分页、定位原话、改名、接着聊，以及 Markdown / JSON 全量导出。

查看、搜索、改名和导出旧记录不切换正在进行的对话，也不取消当前任务。只有「接着聊」或主动新建才更换当前对话。导出位于用户数据目录的 `artifacts/conversations`，桌面程序会打开文件所在位置。

删除对话会删除它的事件、回答与字幕、模型轮次、摘要、任务记录和来自这段对话的个人记忆。删除当前对话会取消其任务与播放，并恢复最近另一段；没有其他对话则创建空对话。已经生成或导出的文件保留。事件 ID 通过单调序列分配，避免删除后复用 ID 导致搜索分页、记忆来源或水位错乱。

个人记忆页支持开关、查看原话来源、修改、忘记。修改与忘记必须收到匹配的后端保存回执后才显示完成；保存失败保留输入。

## 验证

`tests/test_conversation_manager.py` 覆盖文字与字幕搜索、字面特殊字符、日期范围、分页、完整导出、删除隔离、记忆引用与保护、重启、异步摘要、删除与后台请求竞争，以及维护失败后的对话继续。

`apps/desktop/scripts/test-command-receipt.mjs` 和既有 renderer 状态测试验证保存回执、错误清理、独立记录查看与分页。

`scripts/verify_conversation_switcher.mjs` 在独立档案和本机模拟模型 API 下验证聊天主界面切换、标题与最近消息筛选、关闭与键盘焦点、每段对话的输入草稿、新建与发送、任务中途取消，以及 780 / 430 / 320 像素窗口布局；同时核对切换始终不会打开设置窗口。

`scripts/verify_conversation_manager.mjs` 在独立用户档案中启动真实 Electron 和后端，使用本机模拟模型 API 验证正常聊天后的自动记忆、搜索定位、跨对话携带、改名、完整导出、修改、来源跳转、忘记、重启恢复、继续、删除以及紧凑窗口布局。该检查不调用用户的真实模型接口；导出文件真实写入，系统文件浏览器打开动作被替换为记录路径。
