# 0.3.27

这次更新集中处理搜索来源和产品命名。

## 搜索

- Bing 偶尔会返回与查询完全无关的网页。现在会先校验结果与主题或关键词的相关性，无关结果不会交给模型，也不会出现在来源栏。
- 来源栏改为最新优先，并按网址去重，避免重复搜索堆出多张相同卡片。
- 保留“结果没有提到名称时，按原始名称精确重查”的恢复路径。

## 命名与界面

- Ayana / 彩名是角色名，不再作为工具名出现在安装器、窗口标题、托盘、欢迎页和设置界面。
- 安装器产品名留空；程序文件名、安装目录和数据目录继续使用 Ayana，已有配置和升级路径不受影响。
- 快捷方式和卸载列表使用中性名称“桌面伙伴”。
- 移除欢迎页圆形头像、立绘占位和过场动画里的单字“彩”；完整的“彩名”角色名保留。
- 网站同步更新版本、下载链接和品牌区。

## 验证

- 搜索相关性回归测试通过；Bing 无关结果会被拒绝。
- 来源快照按最新优先、同网址去重。
- 安装包与便携版构建、SHA256 和下载链接将在发布时更新。
