# 0.3.22：偷看更可控、表情更完整、思考回复更稳

## 主动观察可控

- 新增「偷看时允许搭话」开关：关闭后仍可观察，但不会主动说一句，观察摘要也不写入对话。
- 「允许彩名偶尔偷看」的随机间隔可在设置中调整（15–600 秒），修改立即生效。
- 设置隐私页直接提供上述开关与间隔输入；默认保持 45–90 秒。

## 表情引导

- 用户上下文新增 `expression_coverage.unused`：本会话还没有实际展示过的表情。
- 角色规则要求台词能自然承载时优先从未展示的表情里选，并让措辞和语气贴向该表情；不得为凑表情编造事实或改写用户处境。
- 两套角色规则与 [表情选择文档](EXPRESSION_SELECTION.md) 同步更新。

## 思考模式与协议健壮性

- 主回复与续接请求启用 DeepSeek 思考模式（max effort）；assistant 轮次回传 `reasoning_content`——带 `tools` 的请求缺少它会被服务端以 HTTP 400 拒绝（本次故障的根因）。
- 同一响应内缺少 key 的 speech 自动补齐 key，错位的 translation 与最早缺少字幕的句子配对；运行时不接受无 key 的 speech 事件。
- 已提交并播放的语音不再被尾部修复失败连带中断。
