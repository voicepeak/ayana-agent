# 手机相关代码迭代索引

手机迭代沿用此前悬浮窗与画中画分支的历史，再按独立功能补充提交。Git 推送只备份和发布源码，不重启正在使用的网关或语音进程。

## 统一分支

手机开发统一维护在 `mobile`，保留与 `main` 的继承关系。此前三个手机分支的提交已完整包含，旧分支名称仅保留在历史交付记录中，不再作为开发入口。

`main` 保存稳定代码；手机分支按需同步 `main` 的更新，测试稳定后再合回。阶段迭代通过提交和版本标签记录。

iOS 自动构建跟随 `mobile`。会发送真实聊天／语音请求的公网探测仅在手动运行时勾选 `run_public_gateway_smoke` 后执行；普通推送不会进行该探测。

## 本轮拆分

后续提交按以下顺序组织；具体提交标识见同分支 Git 历史。

1. **运行时手机接入**：独立手机访问令牌、会话与短期 WebSocket 票据、静态网页入口和 PCM 传输兼容，附隔离服务端测试。这是既有 Agent 的可选手机接入，不替换正在运行的独立手机网关。
2. **本地联调工具**：运行时启动脚本、令牌查看工具及浏览器基础检查。工具按需手动运行，不随 Git 推送执行。
3. **Windows 日语词典路径兼容**：处理含非 ASCII 用户目录的 OpenJTalk 词典加载。
4. **网关拒绝请求的上下文**：携带发起请求的 generation、话题与 turn，避免手机将错误误判成上一轮的迟到消息。
5. **双语默认值与迁移**：默认日语正文、中文翻译；迁移旧默认值，同时保留后续用户选择。
6. **逐句字幕与播放同步**：字幕、翻译、音频齐备后才播放；当前句结束后才展示下一句；取消提前预览和 9 秒强制显示；保留文字降级与等待反馈。
7. **立绘切换动效**：解码完成后切换立绘并上下轻弹，尊重减少动态效果；附乱序音频、翻译迟到及动效的浏览器检查。
8. **称呼校验修复**：允许有限长度、带句末标点的纯汉字称呼，避免正常昵称令整段回复中断；附协议及网关回归。
9. **文档与迭代索引**：明确 build 7 原生安装包、后续网页行为和待加载的后端源码修复之间的区别。
