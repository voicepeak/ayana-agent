# 手机端界面与运行逻辑检查：Android build 4

2026-10-25。本轮修改覆盖独立手机客户端、PWA 离线壳，以及网关拒绝请求时的事件关联。保留工作区原有的桌面端、旧手机服务和 SoVITS 适配器修改。

## 已修复

- 多轮消息按真实接收顺序排列。回复不会再集中堆到所有用户消息后；字幕同时更新实时对白与历史字段，历史和实时对白不重复显示。
- 取消、切换话题、断线、重新激活均隔离旧轮次。迟到的语句、字幕、音频和状态不能重新开始旧回复，也不能污染另一个话题。
- 未展示的生成内容不进入后续模型上下文；已展示的部分回复保留“已打断”标记。刷新后不会把中断中的记录恢复为正在播放。
- 同一条消息发送期间阻止重复提交。发送失败保留输入；草稿按用户和话题分别保存在本机，支持刷新、断网和切换话题。
- 网关拒绝新请求时，错误和失败状态使用请求自己的轮次、话题及 turn 编号，避免手机丢弃错误后一直显示“思考中”。
- WebSocket 增加握手超时、心跳失活处理、后台返回检查；4401 强制刷新凭据。过期的连接尝试不能覆盖新连接的状态。
- 离线和在线事件同时更新连接对象与界面，避免网络恢复后发送键仍被禁用。原生 App 返回前台时检查连接。
- 声音初始化失败不阻止文字发送；音频失败释放正在播放的状态。修复 PCM 子数组偏移、未知格式、空样本和无效音量处理。
- 取消的旧音频不占用新一轮缓冲预算；延迟抵达的音频不会重播已经完整展示的文字。播放时申请保持亮屏，结束或离开后释放。
- 本地事件快照与可变持久化数据分离，避免设置保存意外改变 React 已持有的历史。播放回执通过索引定位语句，避免每 100ms 展开全部历史。
- 设置合并保留已有的主题、语言与声音选项；重新激活时清除旧账号界面状态并按账号恢复设置。
- PWA 构建生成离线资源清单，第一次访问就缓存主脚本、动态模块与样式；首张立绘在 Service Worker 接管前也能缓存。静态资源忽略 `Vary: Origin` 的请求头差异，修复缓存已有脚本仍白屏的情况。
- 缺失的离线图片和脚本返回加载失败，不再拿 HTML 页面冒充资源。开发服务器不注册生产 Service Worker。

## 界面调整

- 使用视觉视口适配软键盘，保留系统缩放；Android 明确使用 `adjustResize`。处理刘海、横屏、小屏与底部安全区域。
- 输入框自动增高，长文本限制与字数提示清晰；滚动查看旧消息时停止自动拉回，并提供“回到最新”。
- 调整对白字号、卡片间距、留白和菜单层级。浅色气泡单独计算深色文字，修复苔绿等深背景主题的对比度。
- 设置面板固定标题、独立滚动，添加 8 套主题、对白/翻译语言、语音回复开关、音量，以及自动保存的称呼和记忆。
- 话题支持搜索、改名、导出和带确认步骤的删除。导出使用系统文件分享或浏览器下载；WebView 不支持文件下载时仍需通过浏览器导出。
- 增加菜单焦点约束、Escape 关闭与焦点恢复、原生菜单返回键处理、输入标签、触摸目标及减少动态效果支持。
- 激活页增加显示/隐藏激活码，关闭自动大写，并说明离线资料与服务在线要求。

## 复验命令

```powershell
npm --prefix apps/mobile test
npm --prefix apps/mobile run build
.venv\Scripts\python.exe -m pytest -q

# 先运行 apps/mobile 开发服务器，再传入本机 Playwright 包目录及浏览器路径
node scripts/verify_mobile_ui.mjs --playwright-root <node_modules目录> --browser <chrome.exe路径>

# 生产 PWA：先运行 npm run preview -- --port 4175
node scripts/verify_mobile_offline.mjs --playwright-root <node_modules目录> --browser <chrome.exe路径>

# 真实服务需要独立网关和 SoVITS 在线；可指定临时用户激活码文件
node scripts/verify_mobile_independent.mjs --playwright-root <node_modules目录> --browser <chrome.exe路径> --activation-file <激活码文件> --online-only --recovery --direct
```

## 仍需实机验证的范围

本轮没有连接 Android 或 iPhone 实机，不能代替系统软键盘、原生安全存储、音频路由、后台恢复与手机运营商网络验证。Android 包仍为已有开发调试签名。iOS 已同步前端资源，本轮没有重新运行 Mac/Xcode 构建或生成新的签名 IPA。

独立 STT、搜索和桌面完整工具迁移仍未实现，麦克风入口继续明确禁用。英文译文缺失时回退中文/日文；界面已说明这一行为。离线只能使用已缓存的网页与立绘、历史和设置，不能离线请求模型或合成声音。
