# Ayana 首批 Agent 能力交付

版本：0.3.0。日期：2026-10-04。

## 已实现

- 原生工具调用：在线模型默认使用 OpenAI 兼容的 `tools` 接口（配置项 `native_tools`），流式解析 `delta.tool_calls`，并以 `role:"tool"` 按 `tool_call_id` 回传结果；与既有 NDJSON 语音/翻译事件并存。真实 DeepSeek 模型在自然语言请求下会自行调用工具（例如直接说“新建文件…保存”即可触发 `files.create`）。端点不支持时可设 `native_tools=false` 退回 NDJSON 工具事件。
- 联网工具：Brave 搜索适配、普通 HTML/纯文本读取、真实来源卡片和外部链接。未配置搜索密钥时明确提示，仍可读取指定网址。
- 文本文件：创建、完整读取、差异预览、确认修改、备份和恢复预览。新建不会覆盖；修改与恢复会检查原文件哈希，遇到外部改动停止。
- 任务循环：工具真实结果进入下一轮模型输入；确认后继续同一任务；暂停、继续、取消和累计预算；任务、文件及来源在“任务与结果”页面展示。
- 桌面衔接：执行结果与新截图回传模型；缺少预期结果证据时显示“结果仍待核实”。既有用户接管、焦点、目标与快照保护保留。
- 基础约束：工具注册与参数校验、调用 ID 防重放、服务端目录授权、路径与 Windows junction 检查、公网地址验证和连接地址固定、有界下载、快照和事件广播。

## 使用

1. 关闭旧版，再双击 `apps/desktop/release/Ayana-0.3.0-win-x64.exe`；开发目录也可使用 `启动 Ayana.cmd`。
2. 在对话框启用执行模式，发送：“读取 https://example.com，把摘要与来源网址保存成 example-note.md。”
3. 打开“设置与管理 → 任务与结果”，查看实际文件和来源。默认文件保存在当前用户数据目录的 `artifacts` 中，卡片显示完整路径。
4. 要修改其他目录，在该页点击“授权文本修改”并选择目录，然后提出修改请求。查看差异，点击“确认这一步”。修改后的文件可“预览恢复版本”，再次确认才恢复。
5. 取消会停止后续步骤并使确认项失效；已经落盘的内容保留。新消息或切换模式会取消旧任务，请先处理当前预览。

搜索需要独立的 Brave API 密钥。可以在启动程序的环境中设置 `AYANA_SEARCH_API_KEY`，或在开发目录执行以下命令，以当前 Windows 用户的 DPAPI 加密保存；输入不会显示：

```powershell
# 便携版的用户配置
.\.venv\Scripts\python.exe scripts/configure_search.py --installed
# 开发目录的用户配置
.\.venv\Scripts\python.exe scripts/configure_search.py
```

设置后重新进入任务页或重启。模型密钥沿用现有配置，搜索密钥不会提交到模型或进入公开配置。

## 范围与限制

首批支持有界 UTF-8 文本，完整文件不超过 64 KiB；模型生成内容还受输出 token 和单事件限制。尚不支持 Office 文件、PDF 编辑、浏览器登录、需要 JavaScript 的动态页面、任意命令执行、提醒和长期事实记忆。

默认每任务 12 轮、24 次工具、180 秒实际执行时间，等待确认和暂停不计时。暂停在下一安全边界生效，当前模型片段可能完成输出。重启后的未完成任务标记中断，不自动恢复执行。

任务元数据保留最近 60 条，来源 100 条，文件记录与恢复备份各最多 200 条；超过保留范围的备份无法恢复，产出的用户文件不删除。备份清理在新记录或启动时进行。既有对话历史仍遵循原来的保存设置，未添加整体历史清理界面。

`save_history=false` 不保存模型轮次、任务对话和来源记录；已经写入的文件、必要恢复记录以及用户明确授权的目录仍保留。目录检查和 Windows 文件共享约束收窄外部并发修改的风险，但不是操作系统级隔离沙箱。

网页来源卡片证明实际读取了哪一页，不自动保证摘要每句话都有来源支持。当前执行模式和逐步确认只允许已注册的文件/桌面操作，尚未提供通用插件执行入口。
