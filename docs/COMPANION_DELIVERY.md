# Ayana v0.2.0 个性化 Agent 界面

呼出入口为透明、无系统边框的半身立绘与对话框。日语回应和中文翻译分别显示，结束后保留最后一句。设置与管理是另一个默认隐藏的窗口，从对话齿轮或托盘打开；关闭设置不取消会话。聊天窗口拥有唯一的音频播放器。

原素材索引的 234 张 PNG 全部导入，26 种表情、9 种服装与姿势组合。导入保留文件字节，不缩放、不重新编码。图像原来已有透明通道，旧版不透明的观感来自界面背景。按统一原图高度缩放并裁出上半身，防止不同姿势的图片宽度导致人物忽大忽小；表情图片提前加载，实际消费语音时才切换。

模型每句输出 `expression` 与 `pose`。后端只解析目录中的素材，并限制在用户选择的服装下；无效选择按 affect 和 intent 回退。纯文字与语音失败时，界面按阅读时长逐句显示。旧版的 2 秒表情门槛和五种固定意图表情不再限制完整目录。服装不由模型自动更换。

立绘静止；换句时向下移动 12px，在 300ms 内回到原位。同一语句的重复回执不会重启动画。设置里可以关闭，系统减少动态效果也会禁用。人设暂改为日常同伴与个性化 Agent 的定位，正式设定等待用户提供。

- 实际开发版和打包后的 Electron：透明背景、半身素材加载、设置隐藏/打开/独立关闭、跨窗口应用设置、纯文字逐句切换与翻译、下沉动画停止、收起流程通过。
- 234 张导入 PNG 与原始文件逐字节一致。
- 真实在线模型按日常问候输出了目录内表情和 `open` 动作，后端成功解析为实际素材 ID。
