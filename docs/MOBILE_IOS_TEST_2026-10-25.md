# Ayana iPhone 原生测试：build 7

本包用于测试聊天、语音和系统画中画，只启用黑 Ayana。安装包尚未签名，普通 iPhone 需要用自己的 Apple Account 签名安装。没有在 App Store 或 TestFlight 发布。

## 安装

需要一台 Windows 或 Mac 电脑和 iPhone 数据线。

1. 在电脑下载并安装 [Sideloadly 官方版本](https://sideloadly.io/)，按其说明安装所需 Apple 设备组件。
2. 连接 iPhone，在手机上确认“信任此电脑”。打开 Sideloadly，选择自己的 iPhone，拖入同目录的 `Ayana-0.2.0-ios-build7-unsigned.ipa`。
3. 使用测试者自己的 Apple Account 签名安装，密码和验证码只在工具登录流程中输入。
4. 按提示信任开发者；iOS 16 及以上如要求开发者模式，在“设置 → 隐私与安全 → 开发者模式”启用。开发者信任位于“设置 → 通用 → VPN 与设备管理”。[官方安装 FAQ](https://sideloadly.io/faq)
5. 打开 Ayana，完整复制本测试包内 `测试激活码.txt` 的一整行并粘贴激活。使用专门的测试账号，无需填写 DeepSeek Key，也无需在手机安装 Tailscale。

免费 Apple Account 签名的应用通常需在 7 天后重新签名；更新时使用同一 Apple Account 与 Bundle ID 覆盖安装，以保留本机数据。需要保留的话题，可先在应用菜单导出。[签名有效期与覆盖安装说明](https://sideloadly.io/faq)

## 按顺序测试

| 步骤 | 操作与观察 |
| --- | --- |
| 连接 | 分别使用 Wi-Fi、蜂窝网络进入应用，确认状态显示已连接；测试时网关电脑需保持在线 |
| 首句反馈 | 发“今天有点累，陪我聊聊”。记录发送至出现首句文字、发送至听见第一句语音的时间。文字出现后可以看到“语音准备中”，声音开始后提示消失 |
| 连续对话 | 再发两轮消息，检查每句字幕与语音不重复、次序一致；长中日文可完整阅读 |
| 打断 | 在语音开始前、播放中分别点打断，再发新消息；已有可见文字保留，旧语音不应接着播放 |
| 打开画中画 | 菜单 → 随身陪伴 → 开启画中画。退回桌面或切到其他 App，观察黑 Ayana、字幕与语音 |
| 系统控件 | 用系统画中画控件暂停、恢复、放大或缩小；长字幕带页码并翻页，不能横向溢出或省略结尾 |
| 返回 | 用系统返回入口回到 Ayana，再输入下一条消息。历史应连续，语音不应重播。输入在主界面完成 |
| 关闭 | 关闭画中画，确认当前回复停止；重新开启仍可继续对话 |
| 中断恢复 | 切后台、锁屏再返回；短暂断网后恢复网络，观察状态和草稿是否恢复。这些行为需要实机反馈 |

## 反馈格式

- iPhone 型号、iOS 版本、build 7。
- 使用 Wi-Fi 还是蜂窝；前台还是画中画。
- 发出的测试句，出现问题前的操作顺序。
- 首句文字约几秒、第一句声音约几秒；是哪一个阶段停住。
- 有错误提示时提供提示文字；排版问题可附截图或录屏。

本轮已做 iOS 原生编译、模拟器文字渲染与传输状态回归；实际签名安装、系统画中画和后台音频以此次 iPhone 测试为准。
