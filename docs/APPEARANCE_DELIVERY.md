# Ayana v0.2.2 呼出与窗口锚定

半身立绘的底部使用 128px 透明渐隐，并与对话框重叠 68px。对话框使用更实的深色底，人物自然隐入框后，避免透明界面露出横向裁切线。原始 PNG、人物比例及表情路由保持原样。

每次呼出时，人物在 480ms 内从下方 26px 淡入到原位，对话框延迟 100ms 后在 360ms 内上移淡入。出现动画使用独立的外层容器，不干扰换句下沉动画。尊重系统减少动态效果设置。

呼出时使用后端在抢焦点前记录的真实前台窗口。独立、透明、不可聚焦且鼠标穿透的高亮窗口，按物理坐标转换后的 DIP 贴合目标窗口；金色细光与四角标记短暂亮起，1.8 秒后隐藏。效果没有内容区底色，不遮挡目标窗口。无目标时仅显示人物，不沿用旧目标；随后更新截图或播放不会重复触发光边。原来的工具局部高亮仍单独显示。

验证：TypeScript、Vite/Electron 构建与桌面播放器/状态检查通过。实际 Electron 中创建并聚焦受控 Win32 窗口，验证目标光边边界与 175% DPI 换算一致、光边不可聚焦、自动隐藏、再次呼出动画、减少动态效果、半身渐隐及原有对话/翻译/设置/换句动画流程。截图位于 `.runtime/benchmarks/companion/`。

打包版的上述交互与真实 GPT-SoVITS 播放也通过，播放器记录了实际消费的音频样本。

升级过程中发现旧进程连续重启服务产生了两个后端；新增重启防重入，实测同时发送两次重启请求后只保留一个后端。
