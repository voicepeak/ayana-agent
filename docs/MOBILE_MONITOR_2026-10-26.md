# 手机测试运行观察面板

本机地址：`http://127.0.0.1:17340/`。

这是独立于手机网关、语音进程的管理员服务。只绑定本机回环地址，不挂载到手机公网入口；启动面板不会重启网关或语音服务，也不发送模型请求或语音合成任务。

## 启动与登录

在项目根目录执行：

```powershell
.\scripts\start_mobile_monitor.ps1
```

使用现有项目 Python 环境。运行前需要已经配置好 `.runtime/mobile-services/gateway.json` 和 `worker.json`。启动脚本在后台运行面板，端口已占用时直接退出，不会终止现有进程。

打开本机地址，使用 `.runtime/mobile-monitor/面板登录信息.txt` 中的管理员口令；`login-url.txt` 是带登录片段的快捷链接。面板登录成功后从地址栏移除口令片段，浏览器会话通过 HttpOnly、SameSite Cookie 保存。不要把管理员口令发给测试者。

账号显示名称来自两个测试者的本地身份文件和可选的 `.runtime/mobile-monitor/labels.json`。没有别名的新账号会显示自己的账号 ID。

## 可以看到什么

- 每 2 秒刷新当前读取窗口，按账号、话题、1／6／24／72 小时筛选；可只看异常、包含已停用账号、暂停刷新、跟随最新。
- 用户消息、生成的日语和中文翻译、模型完成状态、模型或语音错误码。
- 发送至首句文字、中文翻译、首句音频合成就绪的时间；合成本身耗时、完成段数、P50／P95。
- 在查看旧请求时保持选中的请求，手动选择不被新消息抢走；复制文字和滚动阅读也保留位置。
- 查看单轮事件，以及导出当前筛选窗口的文字日志。

## 指标边界

- **完整模型上下文没有采集**：现有服务端没有保存每轮完整 `messages`、系统提示词、手机称呼设置或本机记忆。面板不会把会话记录冒充为完整模型入参，也不会自动判断用户是否修改了人设。
- **合成就绪不是手机出声**：首段计时对应队首语句的合成完成事件，包含此前模型生成、排队及合成等待。后一句先完成，不会被算作首句已经就绪。传输、播放启动和实际听完时间没有采集。
- **等待告警不是确认卡死**：等待超过 30 秒给出提示；超过 180 秒仍缺少后续记录时标为“缺少后续记录”。主动打断、断网、日志延后都可能产生相同表象。
- 首句合成就绪超过 5 秒显示偏慢；模型错误和语音合成错误分开展示，主动取消不算模型错误。
- 已激活设备数是未过期的激活记录，不代表当前在线设备数。
- 尚未持久化的连接断开、请求拒绝和手机播放错误不在现有日志范围内；面板只展示实际保存下来的事件。
- 为控制读取开销，每个日志源最多读取最近 4000 条事件，当前视图最多展示 120 轮，触及上限时显示提示。选择具体账号和话题可缩小显示范围；本工具不是完整历史归档检索器。

## 数据与访问

日志数据库与网关 SQLite 均用 `mode=ro` 和 `PRAGMA query_only=ON` 打开。面板合并持久日志和网关尚待归档的 outbox，并按事件 ID 去重；不会确认、移除或重排原 outbox。

查询身份库只读取账号启用状态和激活设备数量，不读取访问令牌、刷新令牌或激活密钥。API／事件视图移除已知凭据字段、音频载荷，隐藏文本中的完整激活码与常见 API Key。

面板仅有登录、退出与读取接口，不提供重试、封号、修改人设或重启服务的操作。访问记录关闭，响应不缓存，跨源登录被拒绝。登录信息、后台日志、账号导出和测试截图在忽略目录中，不提交到 Git。

## 验证

- 后端 13 项测试通过：只读与 WAL 并发、归档去重、账号筛选、计时和异常分类、队首音频顺序、凭据过滤、认证和来源限制。
- 浏览器使用合成数据检查自动刷新、手动阅读与跟随、模型／语音错误区分、账号筛选、暂停／恢复、导出、消息文本转义和退出。
- 1440、980、390 宽度布局检查无横向溢出，并检查截图调整字号及手机布局。
- 实际日志源已用管理员认证只读查询验证；未向测试者会话发送消息。
