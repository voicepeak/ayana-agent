# 0.3.23：情绪状态、表情轮换、偷看真正发生

## 情绪状态

- 新增跨对话持续的心情状态（mood 与 intensity，加上 energy / patience / warmth 三维），只从每轮已展示的表情增量更新，不额外请求模型。
- 同方向 30 分钟内衰减（1、1/2、1/4…），mood 切换有迟滞与最短停留；离开 7 小时以上视为睡过一觉，深夜精力封顶并倾向困倦。
- 回合上下文新增 `emotion` 块；角色规则要求表情与语气优先与当前心情一致，再考虑本句。

## 表情轮换

- `expression_coverage` 新增 `suggest`：每轮推荐两个「本会话没展示过、与当前心情相容」的表情，用过即轮换；兜底表情（休闲/正经/平静）与保留表情（愤怒/哭/病娇等）不强推。
- 规则明确建议在台词能诚实承载时必须采用，且不能拿「延续上一句」当借口；同一轮多句回复要有自然的细微变化。
- 彩名（白制服）的 25 个表情并入共享心情映射，两套角色都参与心情计算。

## 偷看

- 每次观察机会都会先看一眼：先截图（相同画面跳过模型请求），再让模型决定沉默或说一句；「正在看看屏幕」指示覆盖整次观察。

## 模型设置与协议

- 设置中可调 `temperature`（0–2，默认 1.0）与 `history_budget_chars`（16k–512k，默认 128000），修改立即生效；历史预算同时作用于压缩与摘要分批。
- 请求始终携带配置温度并请求 usage；模型事件流容忍简短引导行与 markdown 围栏。
