# Ayana v0.2.1 语音与姿势修复

发现旧进程使用了默认语音配置，落到未安装的 Windows 日语系统语音；当时磁盘上的个人配置已包含 GPT-SoVITS 路径。未复现 SoVITS 模型本身崩溃。新版启动后端时通过 `--data-dir` 显式传入 Electron 个人配置目录，并记录实际配置路径、是否存在、语音模式和密钥是否已配置，不记录密钥内容。

设置窗口收到真实配置前禁止保存，避免初始默认值覆盖个人配置。更新部分语音字段时保留原来的模型与资源路径。只有语音配置实际改变才重启语音引擎；改变音量、服装或换句动画不会重新加载模型。真正更换语音配置时，先取消并等待旧的启动任务，再关闭旧引擎。

普通回应默认使用双手交叠。模型明确请求摊手时，只有 12% 概率采用，且两次摊手至少间隔四句；直接指定摊手素材 ID 也经过同样限制。所有表情仍可路由。

验证：Python 89 passed、3 skipped；五句真实日语合成以及取消后重新合成通过。开发版与打包版使用中文路径中的独立配置、真实 GPT-SoVITS 和 AudioWorklet，逐句播放与保存显示设置后的再次播放通过。真实便携启动器的个人配置加载、完整音频消费回执及退出/重启检查记录位于 `.runtime/benchmarks/portable-launcher/`。

语音合成结果位于 `.runtime/benchmarks/voice-recovery/tts/`。验证消费样本回执不代表已进行人工听感评测。
