# Ayana 0.3.15 · 2026-10-07

下载：[Windows x64 便携包](https://github.com/voicepeak/ayana-agent/releases/tag/v0.3.15)。个人配置、话题与历史继续保存在 `%APPDATA%/Ayana`；启动新便携包前先退出旧实例。

## 本版改动

- 气泡居中层叠，使用轻边缘、渐变和柔和阴影表现厚度；上下翻阅历史有过渡动画，并遵循系统减少动态效果设置。
- 未回答时显示等待动画，保留上一次已显示的回答。取消、失败和需要确认时结束等待效果。
- 用户最近的消息改为右下方的小卡片；底部文字输入使用紧凑尺寸和独立无衬线字体，移除语音输入与识别语言入口。
- 茶白主题关闭气泡时使用清晰的深色文字，移除黑色描边。字幕字号支持 14–40。
- 主题精简为夜墨、茶白、苔绿、雾蓝和自定义。预设具有光影与简约几何背景；自定义支持图片或纯色，移除透明度控件。
- 调整立绘时支持滚轮缩放；自定义图片支持滚轮缩放、拖动裁切和恢复默认构图。
- 未保存的外观预览在关闭编辑器后撤回；保存失败时恢复已保存的外观，保留编辑草稿供重试。背景图片使用内容标识，替换失败不会覆盖原图。
- 换装保留表情、播放进度和排队语句，不再生成固定的换装台词；不同姿势共享稳定的立绘占位，窄窗口字幕保持在人物侧边。
- 保留异常或取消前的工具证据，限制多轮工具请求与摘要输入大小；重启后协调任务状态，并标记来自旧材料的引用。
