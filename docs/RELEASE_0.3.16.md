# Ayana 0.3.16 · 2026-10-07

下载：[Windows x64 便携包](https://github.com/voicepeak/ayana-agent/releases/tag/v0.3.16)。个人配置、话题与历史继续保存在 `%APPDATA%/Ayana`；启动新便携包前先退出旧实例。

## 本版改动

- 呼出只打开对话，不再绑定前台窗口；再按一次呼出快捷键收起会话。
- 新增注视当前窗口（默认 `Ctrl+Alt+W`）。注视时显示持续光标，跟随窗口并按间隔刷新截图；再按一次解除注视。三个快捷键不能相同。
- 目标窗口最小化或无法截图时，对话继续；模型收到观察不可用的说明，界面不再把截图失败当成整轮错误。关闭发送截图后，注视不再抓取画面。
- 人设改为气质、兴趣和生成原则，不再把示例台词、口头禅或固定收尾送进正式提示。事件协议只说明字段，不附带可复用的句子。
- 长对话里的工具结果不再被固定前缀重复扣减上下文预算，打开应用等跨轮任务可以保留搜索和启动结果。
