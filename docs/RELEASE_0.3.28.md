# 0.3.28

这次更新把 Ayana 的名字和视觉重新做了一版，并给立绘加上随声音变化的 Q 弹反馈。

## 新品牌

- 桌面伙伴正式命名为 **Ayana**。安装器、快捷方式、窗口标题、托盘和网站统一使用这个名字。
- 新 Logo：深墨底色、象牙白衬线 A、朱红四角星；应用图标、托盘、安装器、网站 favicon 和分享图同步更新。
- 网站和应用内的品牌字使用 Lora 粗体（OFL）子集，角色对白中保留完整的中文名「彩名」。
- 移除了欢迎页和过场里的单字「彩」。

## Q 弹立绘

- 新增「随声音 Q 弹」开关（设置 → 今天的模样）。
- 读取 TTS 实际输出的 PCM 音量，立绘随音量做轻微的拉长/压扁，并用弹簧回弹，不再只是上下跳一下。
- 点击立绘会触发一次回弹；切换表情时也会有一记轻弹。
- 尊重系统的“减少动态效果”设置；关闭开关后完全静止。

## 搜索

- 保留 0.3.27 的无关结果过滤、主题名称校验和来源最新优先/按 URL 去重。
