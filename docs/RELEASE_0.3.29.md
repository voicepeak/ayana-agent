# 0.3.29

这次只调 Q 弹立绘的手感。

- 提高弹簧刚度、降低阻尼，回弹更快，松开音频后不会长时间保持扁形。
- 音频包络释放更快；每个音头再叠一记短脉冲，说话时更接近一下一下的 Q 弹，而不是持续压扁。
- 保留“随声音 Q 弹”开关、点击回弹、切换表情轻弹和减少动态效果支持。
- 其余 Logo、Ayana 品牌和搜索来源行为与 0.3.28 相同。
