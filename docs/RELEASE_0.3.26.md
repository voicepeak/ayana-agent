# Ayana 0.3.26

发布日期：2026-10-18

## 首次见面

- 完成互动开屏导览：称呼、对话、按住说话、搜索、屏幕观察、换装、摆放和主题都可以在导览里直接操作并保存。
- 内置三段 Ayana 日语语音片段，开场无需完整语音包；导览动画使用 GSAP，字体随应用离线打包。
- 换装使用彩名自己的黑制服、内衣与裸露状态，不再提供白制服角色入口。
- 主题从四套扩展到八套：夜墨、茶白、苔绿、雾蓝、樱夜、晴空、琥珀、竹月。

## 对话与声音

- 新增全局按住说话快捷键；未安装语音包时，回复从一开始就按纯文字显示，不再反复触发语音合成失败。
- 文字显现时钟跨卡片挂载保留，迟到音频回执不能把当前台词拉回重播，修复等待卡片抽搐与重复播放。
- 语音包下载优先使用 `hf-mirror.com` 镜像，并对大包启用 8 线程分段下载、断点续传与失败回退。
- 「设定成功」语音只在快捷键保存成功时播放。

## 模型与设置

- 移除本地演示模式。打包版启动时将旧 `local` 配置迁移为在线模型；开屏必须配置 API Key 与模型名称后才能进入桌面。
- API Key 可在「设置 → 模型与连接」直接填写、替换和清除，使用当前 Windows 用户的 DPAPI 加密保存在本机，不写入设置文件。
- 整理角色提示词，禁止「我不讨厌哦」「我不介意哦」「我很喜欢哦」等固定句式、每句都用「哦/呢」收尾，以及反复套用同一种安抚模板。
